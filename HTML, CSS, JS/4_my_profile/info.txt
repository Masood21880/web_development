My Profile - HTML Practice

In this practice, I created a simple personal profile webpage using HTML.

I practiced:
- HTML document structure
- Headings using <h1> and <h2>
- Links using the <a> tag
- Opening links in a new tab using target="_blank"
- Images using the <img> tag
- Alternative text using the alt attribute
- Unordered lists using <ul>
- Ordered lists using <ol>
- List items using <li>
- Tables using <table>
- Table headers using <th>
- Table rows using <tr>
- Table data using <td>
- Table sections using <thead> and <tbody>
